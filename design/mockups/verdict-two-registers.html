Same number, one source of truth. Both registers render from one shared spec object {flagged, total, sources[], band, ...} — the analyst Muster, the client card, and the canvas PNG that reaches the client's inbox when HTML email is stripped. The client card is deliberately literal (fraction + word-band + shape-icon + segmented count + ledger) so it's understood in 3 seconds by a non-technical reader with zero training — the thing the abstract Muster couldn't do. Redundant encoding (colour + icon shape + word + count) means it survives greyscale, colour-blindness, and image-blocking mail clients.
