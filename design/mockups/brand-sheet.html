Refining the mug, the wordmark, and the typeface — RADAR direction

Teal on Prussian-slate is settled and stays untouched. This sheet resolves the three things still open on that foundation: which cut of the coffee-mug mark earns the topbar, how "SOCDESK" is cased and locked up next to it, and what replaces Bricolage Grotesque as the display voice — Bricolage has never sat right and the owner has said so more than once. Three options per question, judged in the same dark UI the product actually ships in, not on white paper.

01 · THE MARK

Three cuts of the coffee mug

The mug stays — it is the owner's mark, the sibling of the pixel mug on SanchezOnSecurity.com, and dropping it would sever that link for no gain. What changes is discipline: the current mark's two wispy steam curls are the mascot-cute tell that reads fine at 96px and turns to noise at 24px. Each option below is judged at both sizes, in situ, because a mark that only works large is not a topbar mark.

03 · THE TYPEFACE

Replacing Bricolage Grotesque

Bricolage is out — it's never read right and the owner has flagged it repeatedly. Inter is off the table (this is brand voice, not body UI text) and so is Bricolage's usual understudy, Space Grotesk, which has become the default "distinctive" pick for almost every AI-generated dashboard and reads as a tell rather than a choice at this point. Three real alternatives below, each carried through the wordmark, a nav row, and the actual hero line, with its own paired data-mono.

  • Genuinely uncommon in this category — nothing in the CTI competitive set (brand.md §2.1) is using it, so it reads as chosen, not defaulted.
  • Display and mono are drawn by the same foundry as one family — real shared DNA between the analyst's prose and the record's data, which most pairings on this page fake by yoking together two unrelated type houses.
  • Built for enterprise infrastructure documentation — an engineering pedigree that resonates with a SOC analyst's own daily tools instead of costuming as a "security brand."
  • Red Hat Mono disambiguates 0 with a slash against a round O — load-bearing for hashes, IPs, and CVE IDs quoted verbatim into an escalation.

RISK — two separate variable font files instead of one shared axis system, but both are small Latin-only variable fonts; not a meaningful load-time cost.
