SOCDESK Extension Options

The instance the extension talks to. Default is https://socdesk.io. Point it at a self-hosted deployment if you run your own. Enter a bare origin (scheme + host), e.g. https://socdesk.example.com.

Custom origins: live lookups need host access. This build ships with access to https://socdesk.io and https://socdesk.pages.dev. A custom origin on another domain requires the host to be added to host_permissions in manifest.json and the extension reloaded (see README).
